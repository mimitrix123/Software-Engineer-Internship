# Software-Engineer-Internship
Software Engineering Assignments And Mini Project

## Mini Projects

### Week 2 — Library Management System
A Python CLI library management system demonstrating Factory, Observer, and Singleton design patterns, with SQLite persistence and comprehensive unit tests.

See [`week-2/library-management/README.md`](week-2/library-management/README.md) for setup and usage.

### Week 3 — Blog Platform API
A complete FastAPI blog platform API with JWT authentication, post CRUD, comments, likes, pagination, search, rate limiting, input validation, unit tests, and Swagger/OpenAPI documentation.

See [`week-3/blog-platform-api/README.md`](week-3/blog-platform-api/README.md) for setup and endpoint documentation.

### Week 3 — CLI Task Manager
A Python command-line task manager built with object-oriented design and JSON persistence. The project supports creating, listing, viewing, updating, completing, and deleting tasks with priority and due-date validation.

See [`mini-project/task-manager/README.md`](mini-project/task-manager/README.md) for setup and usage.
